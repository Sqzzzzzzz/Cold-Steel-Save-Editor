# Cold Steel I Inventory Editor v1.0.0

A Windows editor for the Steam PC release of Trails of Cold Steel I. Search the installed game's catalog, edit inventory quantities, review pending changes and save with a backup.

## Installation

1. Download the Windows x64 ZIP and compare its SHA-256 hash with `SHA256SUMS.txt`.
2. Extract the full folder and run `Cold_Steel_I_Inventory_Editor.exe`.
3. Select your Steam game directory if the editor does not find it automatically, then open your most recent compatible slot or choose one manually.

## Highlights

- Add and remove items, edit quantities, undo changes, and compare or export inventories.
- Save a copy or update a slot with a byte-for-byte backup.
- Browse the catalog in an English or Russian interface. The portable archive uses the original English item table and supports optional local art and item translations.

Close the game before overwriting a slot. Only the inventory block is edited. See the [README](https://github.com/Sqzzzzzzz/Cold-Steel-Save-Editor#readme) for recovery steps and supported save formats.
