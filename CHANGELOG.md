# Changelog

## 1.0.0

- Browse the installed Cold Steel I Steam catalog, including fishing records and DLC listings.
- Edit inventory quantities with limits, undo and a pre-save change review.
- Save to a separate file or replace a slot with a timestamped backup. Windows overwrite protects the verified file against in-place writes and preserves a concurrently displaced version for recovery.
- Detect Steam library folders and the Windows Saved Games location. Skip incompatible slots and preserve inventory-independent data.
- Switch between English and Russian. A damaged optional translation pack leaves the original catalog available.
- Display local original game artwork where available, including fish, quartz variants and ARCUS covers.
- Ship a windowed Windows build with a versioned ZIP, SHA-256 checksum and third-party notices.
